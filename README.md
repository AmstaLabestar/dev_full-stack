# HamzaDev Portfolio

Initialisation du portfolio full-stack avec Next.js App Router, TypeScript, Tailwind CSS, ESLint et Prettier.

## Prerequis

- Node.js 22+
- npm 11+

## Scripts

```bash
npm run dev
npm run lint
npm run typecheck
npm run format:check
npm run build
```

## Objectif de l'etape 1

- generer un socle Next.js propre
- activer TypeScript strict
- configurer Tailwind CSS
- configurer ESLint
- configurer Prettier avec tri Tailwind

## Structure initiale

- `src/app` : point d'entree App Router
- `src/app/globals.css` : styles globaux Tailwind
- `eslint.config.mjs` : regles de linting
- `.prettierrc.json` : formatage partage
- `tsconfig.json` : configuration TypeScript

## Verification

Executer les commandes suivantes avant de passer a l'etape 2 :

```bash
npm run lint
npm run typecheck
npm run format:check
npm run build
```
